# gd-business-site-lite-starter

Lite business site starter: a single Next.js 16 site, no backend and no database.

- Stack, rules and ports: `CLAUDE.md`
- Phases: `docs/PHASES.md`; pinned versions: `docs/VERSIONS.md`; template sync policy: `docs/SYNC.md`
- Start: `make up`, then open http://gd-business-site-lite-starter.localhost:28390 (LITE_PREVIEW_PORT)
- Stop: `make down`; build check: `make web`
